# Dmoney Api Testing
## Project Summary
In this project, comprehensive API testing was conducted for the Dmoney portal. It is a role based transaction system.
## Technology
- Postman
- Newman
- HTML Extra Report
## Prerequisite
- Install **Node.js**
## How to run
1. `git clone`
2. `npm i`
3. `npm test`
#### Caution : You must have the .env file to run this project.
